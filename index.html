Wiring this to real hardware

        

          
The cage and the flyway are separate rigs and this tool keeps them separate — own geometry, own receivers, own log. Every number here is generated by a model; the shape of the app is the deliverable.

          
    
            
  • Cage receivers — the 24 bars are all 1500 mm, so a position is a bar name plus a distance from that bar's zero end, the way you'd read it off a tape. Positions are configuration you measure once; power comes from the path Fennec already uses, two DataEndpoints off the VISA load multiplied into a custom endpoint.
    • 
            
  • Flyway mover — PMCLIB.dll is a netstandard2.0 managed assembly, so C# references it directly. ConnectToSpecificPMC(ip), then poll GetAllXbotInfo(POSITION); each XBotInfo carries XPos/YPos/ZPos and RxPos/RyPos/RzPos in metres. Polling only, no push interface.
    • 
            
  • The sweep — LinearMotionSI(...) to each grid point, wait for XBOT_IDLE, take one Snapshot, so position and power are sampled while the mover is stationary.
